# Политика безопасности

## Поддерживаемая версия

Исправления безопасности применяются к последней версии ветки `main`.

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости в обычной Issue. Используйте приватное
сообщение об уязвимости в разделе **Security → Advisories → New draft security
advisory** репозитория.

Укажите:

- затронутую часть приложения;
- шаги воспроизведения;
- возможное влияние;
- известный способ временной защиты.

Команда подтверждает получение сообщения, оценивает риск и готовит исправление
до публичного раскрытия подробностей.
