# Рабочий процесс команды

```text
Backlog → Iteration → Ветка → Pull Request → Ревью → CI → Merge → CI/CD → Release
```

## Ответственность этапов

| Этап | Результат | Ответственный |
| --- | --- | --- |
| Планирование | Приоритет и критерии приёмки | Product Owner |
| Разработка | Код и модульные тесты | Backend/Frontend Developer |
| Проверка | Одобренный Pull Request | Профильный CODEOWNER |
| Контроль качества | Успешные тесты | QA Engineer |
| Поставка | Артефакт и Docker-образ | DevOps Engineer |
| Приёмка | Закрытая задача и версия | Product Owner |

## Состояния работы

- **Todo** — задача готова к началу;
- **In Progress** — ведётся разработка;
- **QA Review** — выполняется проверка результата;
- **Done** — критерии готовности выполнены.

Количество одновременно выполняемых задач ограничивается на Kanban-доске,
чтобы команда завершала начатую работу до открытия новой.
